## 比較の基本式

ファンドと指数は、同一開始日・同一終了日・同一通貨・配当再投資込みで比較する。

`超過収益 = ファンドのトータルリターン − 比較指数のトータルリターン`

ただし、超過収益だけでは不十分である。次も同時に確認する。

- 年率ボラティリティ
- 最大ドローダウン
- 下方偏差
- 回復期間
- ベータと残差リターン
- 売買回転率
- 信託報酬・実質コスト
- 為替エクスポージャー

## 再計算で禁止する比較

| 禁止事項 | 理由 |
|---|---|
| ファンド設定日と指数の長期履歴をそのまま比較 | 対象期間が一致しない |
| 分配金込みファンドと価格指数を比較 | 配当条件が不一致 |
| 円建てファンドと現地通貨指数を比較 | 為替効果を超過収益と誤認 |
| 最新ファンドだけ生存者として選ぶ | サバイバーシップバイアス |
| 最も良い開始日だけを採用 | 期間選択バイアス |
| 信託報酬を無視 | 長期差の主要因になり得る |

## 必須の出力

### 1. 同一期間比較

- 日次または月次のトータルリターン
- 年率リターン
- 年率ボラティリティ
- 最大ドローダウン
- 最悪月
- 回復までの日数

### 2. ローリング評価

| 窓 | 用途 |
|---|---|
| 1年 | 短期の相対優位 |
| 3年 | 運用サイクル |
| 5年 | 継続性 |
| 設定来 | 長期実績。ただし期間差に注意 |

各窓について、指数超過率、情報比、勝率を表示する。

### 3. 要因分解

超過収益を以下へ分ける。

- 市場ベータ
- サイズ・バリュー・モメンタム
- 業種配分
- 銘柄選択
- 為替
- 現金比率
- コスト

## 2026年の追加注意点

- AI・半導体関連への集中で、ファンド間の名称差より実質ファクターが近づく可能性
- 金利水準が高く、現金保有が以前より大きな収益源になる可能性
- 円高・円安で海外資産ファンドの円建て成績が大きく変わる
- 高配当・バリュー・グロースの分類が業種集中を隠す可能性

## 判定基準

ファンドを「指数より優れている」と判定するには、次をすべて満たす必要がある。

1. コスト控除後で超過収益が正
2. 複数開始日で結果が再現
3. 最大ドローダウンが許容範囲
4. 超過収益が単一業種・単一局面だけに依存しない
5. ローリング3年の勝率が十分高い
6. ファクター調整後アルファが残る
