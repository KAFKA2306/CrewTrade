# 指数ETF比較の再現性監査

更新基準日: 2026-08-04

## 結論

現行設定は4つの指数ラベルだけで、ETFを一意に識別できません。ティッカー、ISIN、正式な連動指数、通貨、為替ヘッジ、分配条件、費用がないため、比較結果を再現できません。商品マスターを先に整備し、比較条件が一致した対象だけを定量評価します。

## データ

ETFごとに必要な項目を10項目へ固定します。

1. ティッカー
2. ISIN
3. 正式商品名
4. 正式な連動指数名
5. 価格指数・グロス配当込み・ネット配当込みの区分
6. 基準通貨・評価通貨
7. 為替ヘッジ条件
8. 分配頻度と再投資条件
9. 信託報酬・その他費用
10. 設定日・履歴開始日

現行設定は各対象について指数ラベル1項目だけを保持します。必須10項目に対する構造的充足率は10%です。

1655を公式情報で照合すると、単なる「S&P500」ではありません。

| 項目 | 公式情報 |
| --- | --- |
| 正式名称 | iシェアーズ S&P 500 米国株 ETF |
| ISIN | JP3048530004 |
| 連動指数 | S&P 500 in TTM Rates Index - Net Total Return (JPY) |
| 基準通貨 | JPY |
| 信託報酬 | 税込年0.0660%程度 |
| 設定日 | 2017-09-27 |
| 分配頻度 | 年2回 |

## 定量分析

現行4対象について、再現可能性を構成する主要フィールドの充足数を監査しました。

| フィールド | 充足数 | 充足率 |
| --- | ---: | ---: |
| ティッカー | 0/4 | 0% |
| ISIN | 0/4 | 0% |
| 正式指数名 | 0/4 | 0% |
| 通貨条件 | 0/4 | 0% |
| 配当区分 | 0/4 | 0% |
| 為替ヘッジ | 0/4 | 0% |
| 費用 | 0/4 | 0% |
| 設定日 | 0/4 | 0% |

比較期間の指定だけでは条件を揃えられません。4商品すべてについて10項目が揃うまで、優劣の数値を生成しません。

## 評価

| 評価軸 | 点数 | 判定根拠 |
| --- | ---: | --- |
| 商品識別 | 0/5 | ティッカー・ISINなし |
| 指数定義 | 1/5 | 通称のみ |
| 通貨・ヘッジ | 0/5 | 未登録 |
| 費用・分配 | 0/5 | 未登録 |
| 履歴比較 | 1/5 | 期間だけ指定、共通開始日なし |
| **合計** | **2/25** | **評価: 現行比較は再現不能** |

## 限界と反証条件

- 1655の仕様を他の商品へ流用しません。
- 10項目が揃い、同一通貨・同一配当条件・同一期間へ正規化できるまで比較値を公開しません。
- 市場価格の売買スプレッドと基準価額のトラッキング差を分離します。
- 指数変更や費用改定があれば履歴を分割します。
