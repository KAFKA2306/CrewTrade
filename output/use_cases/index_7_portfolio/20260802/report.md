# 7指数ポートフォリオ — 2026年8月2日

## 結論

旧スナップショットの最適配分と実績値は、2026年8月時点の価格系列で再計算していない。したがって、過去のウェイト・Sharpe・最大ドローダウンを現在の推奨配分として扱わない。

今回の更新では、2026年7月末の市場環境をストレス条件へ反映し、次回再計算の判定基準を固定する。

## 現在の市場アンカー

| 要因 | 2026年7月末の状態 | ポートフォリオへの影響 |
|---|---|---|
| 米政策金利 | 3.50〜3.75% | キャッシュ・短期債の期待収益が高い |
| 米2年債 | 4.28% | 短中期債にも価格変動余地 |
| 米10年債 | 4.75% | 長期債デュレーションの下落リスクが大きい |

| 金 | 上期に5500ドル超から4000ドル割れまで変動 | ヘッジ資産だが短期ボラティリティが高い |
| 半導体 | メモリ・ロジック集中型の急成長予測 | 株式指数間の実質相関が上がる可能性 |

## 再計算で固定する条件

1. 各指数を同一通貨のトータルリターンへ統一
2. 配当込み・税引前を基本とし、別途税引後を表示
3. 月末リバランスと無リバランスを比較
4. 売買コスト、信託報酬、為替ヘッジコストを明示
5. 最適化期間と評価期間を分離
6. 期待リターン推定に直近上昇率だけを使わない
7. ウェイト上限を設定し、極端な集中解を禁止

## 必須の評価指標

| 指標 | 目的 |
|---|---|
| 年率リターン | 成長性 |
| 年率ボラティリティ | 通常時の変動 |
| 最大ドローダウン | 危機時の損失 |
| Calmar ratio | 下落に対する収益効率 |
| Sortino ratio | 下方変動への耐性 |
| 最悪月・最悪四半期 | 短期資金需要との整合 |
| 回復期間 | 含み損を抱える時間 |
| 資産別損失寄与 | 見かけ上の分散を排除 |

## 2026年ストレスシナリオ

### 金利再上昇

- 10年債利回り: +100bp
- 長期債価格下落
- 高PER株のバリュエーション圧縮
- 金はドル・実質金利との組合せで方向が分かれる

### AI設備投資失速

- 半導体・情報通信指数の同時下落
- 見かけ上異なる株式指数の相関上昇
- クレジットスプレッド拡大を伴う場合は複合ショック化

### 景気後退

- 株式と景気敏感資産が下落
- 短期金利は低下しても長期債が必ず上昇するとは限らない
- 金、国債、現金の防御力を別々に評価

### 円高

- 外貨資産の円換算リターンが悪化
- 為替ヘッジ有無で結果を分離
- 円建て国内資産との相関が変化

## 暫定運用判断

- 過去最適ウェイトをそのまま維持しない
- 株式指数を名称ではなく共通ファクターで集約する
- 長期債は安全資産ではなくデュレーション資産として扱う
- 証券担保ローンを併用する場合、最大ドローダウンではなく強制売却ラインから逆算する
- 次回は2026年7月31日までのデータで再計算する
