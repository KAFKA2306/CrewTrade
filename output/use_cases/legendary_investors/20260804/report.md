# 著名投資家リサーチの開示監査

更新基準日: 2026-08-04

## 結論

現行設定はSoros Fund ManagementとDuquesne Family Officeの銘柄記号を固定配列で保持していますが、SEC提出書類のアクセッション番号、報告対象日、提出日、保有額、株数、変更量を保存していません。この状態では「現在の保有」や「投資判断原則」を再現できません。最新の利用可能な標準四半期13Fは、両社とも2026年3月31日基準、2026年5月15日提出です。評価対象を人物像ではなく、提出書類の差分と開示限界へ変更します。

## 定量分析

- 四半期末から提出までの遅延: 45暦日
- 更新基準日から見た保有情報の観測時点遅延: 126暦日
- 提出日から更新基準日まで: 81暦日
- 現行銘柄配列の来歴充足率: 0/6 = 0%（2主体 × 3来歴項目）
- 銘柄ごとの株数・市場価値・前四半期差分の充足率: 0/13 = 0%

13Fから取得できるのは四半期末時点の対象証券のロング保有です。現金、空売り、四半期内売買、提出後の変更を同じ表からは復元できません。したがって、13銘柄の単純なその後リターンを「著名投資家の運用成績」と呼びません。

新しい分析単位を次へ固定します。

1. `manager_cik + accession_number + report_period`
2. CUSIPまたはFIGIによる銘柄同定
3. 株数・公正価値・ポートフォリオ比率
4. 前四半期との新規・追加・削減・売却差分
5. 提出日以後にしか利用できないポイント・イン・タイム評価
6. SPYだけでなく業種・サイズ・スタイル因子調整

## 限界と反証条件

- 13F記載銘柄を現在保有と表示しません。
- 人物名と提出主体を混同しません。George Soros個人の13F-NTは保有をSoros Fund Management LLCが報告する通知です。
- 修正13Fが提出された場合は旧版を上書きせず、アクセッション番号単位で履歴化します。
- 連続8四半期以上のポイント・イン・タイム差分が揃うまで、判断原則の再現性を高く評価しません。
