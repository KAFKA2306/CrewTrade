# 著名投資家リサーチ — 2026年8月2日

## 結論

2026年8月2日時点で、米国のForm 13Fから確認できる標準的な最新四半期は**2026年3月31日終了分**である。2026年6月30日終了分の提出期限は2026年8月14日であり、現時点ではQ2ポートフォリオを網羅的に比較できない。

したがって、最新の保有銘柄を断定したり、Q1開示を現在のポジションとみなしたりしない。13Fは最大45日の遅延があり、空売り、現金、非上場資産、海外上場株、デリバティブの全体像を示さない。

## Berkshire Hathawayの確認例

SEC EDGARには、Berkshire Hathaway Inc.の2026年3月31日終了四半期のForm 13F-HRが掲載されている。これは四半期末時点の対象証券保有を示すが、2026年8月2日の現在ポートフォリオを保証しない。

## 13Fの正しい読み方

### 確認できること

- 四半期末時点の対象米国上場証券
- 報告価額と株数
- 前四半期との増減
- 集中度と主要ポジション

### 確認できないこと

- 取得価格と売却価格
- 四半期内の売買経路
- 現金比率
- 空売りポジション
- 多くのデリバティブ
- 非上場企業や完全子会社
- 報告日以降の売買

## 分析手順

1. SEC EDGARの原本を取得
2. CUSIP、銘柄名、株数、報告価額を正規化
3. 株式分割・合併・スピンオフを調整
4. 前四半期との差分を株数ベースで計算
5. 価格変動による評価額増減と売買を分離
6. 13D/13G、Form 4、年次報告書と照合
7. 投資家の発言ではなく実際の資本配分と比較

## 再現可能な判断原則

著名投資家の銘柄を追随するのではなく、次を抽出する。

| 原則 | 検証方法 |
|---|---|
| 集中投資 | 上位5銘柄比率と保有期間 |
| 資本配分 | 自社株買い、配当、M&A、現金の使い方 |
| 競争優位 | ROIC、粗利、顧客維持、価格決定力 |
| 財務耐久力 | ネットキャッシュ、満期、FCF |
| バリュエーション | 取得時点の利益・FCF・資産価値 |
| 売却規律 | 事業悪化、価格上昇、代替機会のどれか |
