# 半導体サイクルのデータ・ビンテージ監査

更新基準日: 2026-08-04

## 結論

半導体市場は2025年に過去最高の7,956億ドルへ拡大しました。ただし、2026年9,750億ドルというWSTS予測は2025年見込み7,720億ドルを基準に作られた別ビンテージです。後から確定した2025年実績と機械的につなぐと、2026年成長率は26%超ではなく22.5%になります。予測公表時点の前提と確定実績を混在させず、会社株価ではなく数量・製品群・地域・設備投資へ分解します。

## データ

| データ・ビンテージ | 2025年 | 2026年 | 公表内容 |
| --- | ---: | ---: | --- |
| WSTS Autumn 2025予測 | 7,720億ドル | 9,750億ドル | 2025年+22%、2026年+25%超 |
| WSTS 2025確定値 | 7,956億ドル | - | 2025年+26.2% |

2025年確定値では、Q4市場規模は2,389億ドル、前年同期比38.4%でした。WSTSはAutumn 2025時点で2025年の成長をLogic +37%、Memory +28%、Sensors +10%、Microprocessors +8%、Analog +7%、Optoelectronics +4%と見込んでいました。

WSTSの無料Historical Billings Reportは2026年5月まで更新済みです。2026年6月分のBlue Bookは2026年8月3日公開予定ですが、詳細月次表は会員ポータルの公開条件に従います。

## 定量分析

ビンテージ別の計算を分離します。

- Autumn 2025予測内の2026年成長率: `975 / 772 - 1 = 26.3%`
- 2025年確定値を分母にした参考値: `975 / 795.6 - 1 = 22.5%`
- 2025年予測と確定値の差: `795.6 - 772 = 23.6`十億ドル
- 2025年予測の上方誤差: `23.6 / 772 = 3.1%`
- 2025年Q4の年間売上構成比: `238.9 / 795.6 = 30.0%`

この差は予測が誤りという意味ではなく、予測作成後に2025年実績が上振れしたためです。予測評価では、当時利用可能だった分母を固定し、後日確定値で過去の成長率を上書きしません。

現行の10社株価比較は、企業の事業構成が異なります。NVDA・AMDの設計、TSMのファウンドリ、ASML・LRCXの製造装置、MUのメモリ、ADIのアナログを同じ「半導体株」リターンだけで評価しません。売上成長を、Logic、Memory、Analog、Discrete、Optoelectronics、Sensors、地域、設備投資へ対応付けます。

## 限界と反証条件

- 2026年9,750億ドルを確定実績として表示しません。
- 2025年確定値とAutumn 2025予測を同一ビンテージとして接続しません。
- 株価上昇を半導体出荷数量の成長と同一視しません。
- 最新月次値はWSTSの公開範囲・利用条件を確認した上で保存します。
- Logic・Memory以外の回復が鈍化し、地域別成長が集中する場合は「全面的なサイクル回復」の評価を引き下げます。
