貴金属スプレッドのデータ契約監査

更新基準日: 2026-08-04

結論

現行設定は期間2年、20日ローリング、z値閾値2.0だけを持ち、対象金属、ベンチマーク、AM/PM、通貨、単位、休日、ライセンスを定義していません。LBMAの金・銀・白金・パラジウム価格は国際ベンチマークですが、履歴表の利用・再配布にはライセンスが必要です。無許諾の第三者価格を混在させず、利用可能な公式集計値で基準比率と市場流動性を評価し、日次シグナルはデータ契約が整うまで停止します。

データ

LBMAが公表した2025年の実績平均価格は次のとおりです。すべてLBMAのPMベンチマークに基づく年平均です。

白金 1,274.73ドル

定量分析

2025年平均価格から作る参考比率は次です。

  • 金銀比: 3431.54 / 40.03 = 85.72
  • 金白金比: 3431.54 / 1274.73 = 2.69
  • 白金パラジウム比: 1274.73 / 1150.29 = 1.11

ただし、年平均の比は「各日の価格比の平均」と一致しません。日次平均回帰シグナルへ転用しません。

取引総額の流動性差は大きく、金は銀の5.93倍、白金の57.83倍、パラジウムの144.88倍です。単一の20日z値閾値を4市場へ共通適用すると、流動性・取引時間・価格形成の差を無視します。各ペアについて、対数価格比、中央値絶対偏差、構造変化検定、売買コストを別々に推定します。

評価

評価軸 点数 判定根拠
ベンチマーク定義 1/5 現行設定に対象系列なし
単位・時点整合 0/5 AM/PM・通貨・単位なし
データ利用権 1/5 ライセンス契約を未定義
統計モデル 2/5 ローリング窓と閾値のみ
流動性調整 0/5 市場規模差を未反映
合計 4/25 評価: 日次シグナル停止、データ契約から再構築

限界と反証条件

  • 年平均価格から日次z値を作りません。
  • AMとPM、現物と先物、ドルと円、トロイオンスとグラムを混在させません。
  • LBMA履歴を保存・再配布する場合は必要なライセンスを確認します。
  • ライセンス済みの日次4系列が揃い、欠損日・休日・時点を統一できた後にのみ平均回帰検定を再開します。
  • ADF検定だけで定常性を断定せず、構造変化とアウト・オブ・サンプル損益を併用します。
