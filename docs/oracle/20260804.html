Oracle実績・設備投資回収監査

更新基準日: 2026-08-04

結論

現行設定の基準四半期はFY2026 Q2であり、2026年6月10日に公表されたFY2026 Q4・通期実績より古い状態です。OracleはFY2026売上高674億ドル、クラウド売上340億ドル、営業キャッシュフロー320億ドルを計上した一方、フリーキャッシュフローはマイナス237億ドルでした。RPOは6380億ドルへ増加しましたが、売上への転換時期と設備投資資金の回収を分けて評価します。

会社はFY2027 Q1について、米ドルベースの売上成長率27%から29%、クラウド売上成長率58%から64%を示しました。会社実績・会社ガイダンスと、CrewTradeの独自シナリオを別系列に保存します。

定量分析

公式公表値から次を計算しました。

  • FY2026クラウド売上比率: 340 / 674 = 50.4%
  • Q4クラウド売上比率: 99 / 192 = 51.6%
  • Q4クラウド内IaaS比率: 58 / 99 = 58.6%
  • FY2026 GAAP営業利益率: 206 / 674 = 30.6%
  • 営業キャッシュフロー率: 320 / 674 = 47.5%
  • フリーキャッシュフロー率: -237 / 674 = -35.2%
  • RPO / 年間売上高: 6380 / 674 = 9.47倍
  • Q4 RPO純増率: 850 / (6380 - 850) = 15.4%
  • 前払・顧客提供ハードウェア / RPO: 750 / 6380 = 11.8%

RPOの大きさは需要の契約残を示しますが、売上認識の時期、解約条項、電力・GPU・データセンター供給制約を直接示しません。営業キャッシュフローが大きくてもフリーキャッシュフローが赤字であるため、成長率だけで設備投資回収を肯定しません。

限界と反証条件

  • RPOを将来売上として一括計上しません。
  • 前払・顧客提供ハードウェアを現金収入や利益と同一視しません。
  • FY2027四半期ごとに売上成長、設備投資、減価償却、営業キャッシュフロー、フリーキャッシュフローを追跡します。
  • フリーキャッシュフローが継続的に黒字化し、RPOの売上転換率が上がれば評価を引き上げます。
  • 売上成長がガイダンス下限を下回り、RPO増加と現金化の乖離が拡大すれば評価を引き下げます。
