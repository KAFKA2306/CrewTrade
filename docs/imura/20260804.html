結論

現時点で確認できる一次情報からは、運用優劣を確定できません。評価できるのは、国内株への集中投資、2025年1月27日の運用開始、購入受付停止、基本報酬年1.87%、ハードルレート年6%を超える部分への実績報酬22%、換金時0.3%という高い費用ハードルと短い実績期間です。したがって判定は「優秀」ではなく、費用控除後アルファの継続性を検証中とします。

定量分析

比較対象の年間費用を0.066%のS&P500 ETFと仮定した場合、基本報酬差だけで年約1.804ポイントです。ただし本ファンドは国内株集中型なので、これは運用対象の適切なベンチマークではなく、費用規模の感度分析です。

実績報酬の単純感度を示します。HWM調整前の概算で、年間グロス収益率が15%、ハードル6%を9ポイント上回る場合、実績報酬相当は 9% × 22% = 1.98%。基本報酬と合わせた費用負担の規模は約3.85ポイントとなります。実際の金額は日々の基準価額、HWM、期中解約、その他費用で異なります。

このため評価すべき指標は単純リターンではなく、次です。

  1. TOPIX配当込みに対する費用控除後アルファ
  2. 小型・バリュー・低流動性因子を調整したアルファ
  3. 月次アクティブリターンの情報比
  4. 最大ドローダウンと下方捕捉率
  5. 解約流出時の現金比率・売買コスト・希薄化影響

限界と反証条件

  • 公式の日次基準価額を静的かつ機械取得できる一次データ経路を確認できていないため、最新リターン値を掲載しません。
  • 13か月以上の月次リターンが揃った後も、因子調整後アルファの95%信頼区間が0を跨ぐ場合は、超過収益を実証済みとしません。
  • 費用控除後アルファ、情報比、最大ドローダウンが同一期間の比較群を継続的に上回れば評価を引き上げます。
  • 解約対応による現金確保が長期化し、投資比率低下が基準指数への劣後要因となる場合は評価を引き下げます。
