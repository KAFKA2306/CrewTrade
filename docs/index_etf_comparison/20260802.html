指数ETF比較 — 2026年8月2日

結論

ETF比較では、指数名や過去リターンより先に、何のリスクを保有しているかをそろえる必要がある。旧レポートで扱った国債、金、日本株、高配当株、REIT、新興国株・債券、業種指数は、2026年の金利・為替・AI設備投資環境では異なる形で反応する。

本更新では各商品の最新基準価額、信託報酬、トラッキング差を再取得していないため、旧数値を現在値として転載しない。比較軸と再取得対象を更新する。

2026年に重要な比較軸

1. 指数リターンとETFリターンを分離

  • 指数が配当込みか価格指数か
  • 円換算か現地通貨か
  • 為替ヘッジの有無
  • 信託報酬、売買コスト、税、先物ロール
  • 分配金再投資の有無

2. 債券ETFは年限をそろえる

2026年7月31日時点で米国債は2年4.28%、10年4.75%、30年5.27%。同じ「米国債」でも、短期債と長期債では金利変動への感応度が大きく異なる。利回りだけでなく実効デュレーションと最悪月を比較する。

3. 高配当を低リスクとみなさない

高配当指数は金融、通信、資源、不動産へ偏ることがある。配当利回りが高くても、利益減少、減配、金利上昇、構成銘柄集中で下落し得る。

4. 金と国債は同じ防御資産ではない

金は2026年上期に5500ドル超から4000ドル割れまで大きく変動した。国債は信用リスクが低くてもデュレーション損失がある。危機時の相関は固定ではない。

比較の判定順序

  1. 投資対象と指数定義が一致しているか
  2. 通貨・配当・税・期間がそろっているか
  3. 流動性と売買スプレッドが許容範囲か
  4. トラッキング差が安定しているか
  5. 最大下落と回復期間が目的に合うか
  6. コスト差が期待超過収益を上回らないか
